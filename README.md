# แผนที่แปลงกาแฟ

เว็บแผนที่สาธารณะ 2D/3D แสดงแปลงกาแฟ พร้อมหมุดพาโนรามา 360° ภาพถ่าย ภาพถ่ายทางอากาศ วีดีโอ และข้อมูลอื่นๆ ผู้แก้ไขที่เข้าสู่ระบบเพิ่มหรือแก้ข้อมูลได้จากหน้าเว็บโดยตรง

- หน้าเว็บ: ไฟล์ static วางบน **GitHub Pages** (ฟรี)
- ฐานข้อมูล + ไฟล์ + บัญชีผู้แก้ไข: **Supabase** (PostgreSQL + PostGIS, แพ็กเกจฟรีได้ฐานข้อมูล 500 MB และพื้นที่ไฟล์ 1 GB)
- แผนที่ฐาน: OpenFreeMap (ข้อมูล OpenStreetMap), ภูมิประเทศ 3D จาก AWS Terrain Tiles, ภาพดาวเทียม Esri — ทั้งหมดใช้ได้โดยไม่ต้องมีคีย์

ถ้ายังไม่ตั้งค่า Supabase เว็บจะเปิดใน **โหมดสาธิต** ใช้ข้อมูลตัวอย่างและทดลองแก้ไขได้ แต่ข้อมูลเก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น

---

## 1. ลองเปิดในเครื่องก่อน

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ ถ้าดับเบิลคลิกเปิดไฟล์ `index.html` ตรงๆ ภาพพาโนรามาจะไม่โหลด

```
cd Documents\coffee-map
python -m http.server 8000
```

แล้วเปิด <http://localhost:8000> หรือใช้ส่วนเสริม **Live Server** ใน VS Code ก็ได้

## 2. สร้างฐานข้อมูล Supabase

1. สมัครที่ <https://supabase.com> แล้วกด **New project** เลือก Region **Southeast Asia (Singapore)**
2. ไปที่ **SQL Editor > New query** วางเนื้อหาไฟล์ `sql/schema.sql` ทั้งไฟล์ แล้วกด **Run**
   คำสั่งนี้สร้างตาราง `plots`, `media`, `profiles`, สิทธิ์ (RLS) และที่เก็บไฟล์ `media` ให้ครบ
3. ไปที่ **Authentication > Users > Add user > Create new user** ใส่อีเมลและรหัสผ่านของคุณ (ติ๊ก Auto Confirm)
4. กลับไปที่ SQL Editor แล้วรันคำสั่งนี้ (เปลี่ยนอีเมล) เพื่อตั้งตัวเองเป็นผู้ดูแล

   ```sql
   insert into public.profiles (id, display_name, role)
   select id, 'ผู้ดูแลระบบ', 'admin' from auth.users where email = 'you@example.com'
   on conflict (id) do update set role = 'admin';
   ```
5. ไปที่ **Project Settings > API** คัดลอก **Project URL** และคีย์ **anon public**
6. เปิดไฟล์ `js/config.js` แล้ววางค่าทั้งสองลงใน `SUPABASE_URL` และ `SUPABASE_ANON_KEY`
   คีย์ anon เปิดเผยได้ เพราะ RLS คุมไว้ว่าคนทั่วไปอ่านได้อย่างเดียว ห้ามใส่คีย์ `service_role` ในไฟล์นี้เด็ดขาด
7. ปิดการสมัครสมาชิกเอง: **Authentication > Sign In / Providers > Email** ปิด **Allow new users to sign up** เพื่อให้มีแต่บัญชีที่คุณสร้างให้เท่านั้น

## 3. เผยแพร่บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `coffee-map` (Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวม `.nojekyll`) ขึ้นไปที่ราก repository
3. ไปที่ **Settings > Pages** เลือก Source = **Deploy from a branch**, Branch = `main` / `(root)`
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/coffee-map/`
5. ใน Supabase ไปที่ **Authentication > URL Configuration** ใส่ URL นี้ใน **Site URL**

โฟลเดอร์ `demo/` ใช้เฉพาะโหมดสาธิต หลังเชื่อม Supabase แล้วจะลบออกก็ได้

## 4. การใช้งาน

**ผู้ชมทั่วไป**
- กด 2D / 3D เพื่อสลับมุมมอง ใน 3D ใช้คลิกขวาลาก หรือสองนิ้วบนมือถือ เพื่อเอียงและหมุนแผนที่
- กด แผนที่ / ดาวเทียม เพื่อเปลี่ยนแผนที่ฐาน
- ปุ่มสีมุมล่างซ้ายใช้เปิดหรือปิดหมุดแต่ละชนิด
- คลิกแปลงหรือหมุดเพื่อเปิดข้อมูล ปุ่มลิงก์ในแผงข้อมูลจะคัดลอกลิงก์ตรงไปยังแปลงหรือรูปนั้น (`?plot=CF-001`) ใช้ทำ QR code ติดแปลงได้

**ผู้แก้ไข** (กด "แก้ไขข้อมูล" มุมขวาบน)
- **+ แปลงใหม่** วาดขอบเขตบนแผนที่ (คลิกวางจุด ลากจุดเพื่อย้าย คลิกขวาที่จุดเพื่อลบ กด Enter หรือ "เสร็จ") แล้วกรอกข้อมูล
- **+ หมุด / สื่อ** เลือกชนิด แนบไฟล์ หรือใส่ลิงก์ YouTube
  - ภาพที่มีพิกัด GPS ในไฟล์ (ภาพจากโดรนหรือมือถือที่เปิดตำแหน่งไว้) จะปักหมุดและใส่วันที่ให้อัตโนมัติ
  - เลือกหลายภาพพร้อมกันได้ ระบบจะสร้างหมุดแยกให้ทีละภาพตามพิกัดของแต่ละไฟล์
  - ภาพอัตราส่วน 2:1 จะถูกตั้งเป็นพาโนรามาให้เอง
  - ไฟล์ที่ไม่มีพิกัด ใช้ปุ่ม "เลือกตำแหน่งบนแผนที่" "ใช้ตำแหน่งของฉัน" หรือพิมพ์พิกัดเอง
- ลากหมุดบนแผนที่เพื่อย้ายตำแหน่งได้ทันที
- **นำเข้าแปลงจากไฟล์** (เฉพาะผู้ดูแล) รองรับ KML, GeoJSON (พิกัด WGS84) และ Shapefile ที่บีบอัดเป็น .zip (ถ้ามีไฟล์ .prj ใน zip ระบบแปลงพิกัดให้เอง เช่น UTM 47N)
- **ส่งออก GeoJSON** ดาวน์โหลดแปลงและหมุดทั้งหมดไปเปิดใน QGIS / ArcGIS Pro

## 5. เพิ่มเจ้าของแปลงคนอื่น

1. สร้าง user ใน **Authentication > Users**
2. ให้สิทธิ์เป็นเจ้าของแปลง

   ```sql
   insert into public.profiles (id, display_name, role)
   select id, 'ชื่อเจ้าของ', 'owner' from auth.users where email = 'owner@example.com';
   ```
3. เปิดแปลงนั้นบนเว็บด้วยบัญชีผู้ดูแล > แก้ไขข้อมูล > ใส่ **owner_id** (คัดลอก User UID จากหน้า Users)

เจ้าของแปลงจะแก้ได้เฉพาะแปลงของตัวเอง ส่วนแปลงที่ไม่ติ๊ก "เผยแพร่" จะมีแต่ผู้ดูแลและเจ้าของที่เห็น

## 6. ภาพถ่ายทางอากาศ (ออร์โธ)

**แปลงเล็ก (ไม่กี่สิบไร่) — ภาพเดี่ยว**
ส่งออก orthomosaic จาก Metashape / QGIS เป็น JPG หรือ WebP ขนาดไม่เกิน 50 MB จดขอบเขตเป็นองศา (ตะวันตก, ใต้, ตะวันออก, เหนือ) แล้วอัปโหลดในฟอร์มแก้ไขแปลง

**แปลงใหญ่หรืออยากได้ความละเอียดเต็ม — XYZ tiles**

```
gdal2tiles.py --xyz -z 14-21 -w none --processes=4 ortho.tif ortho/CF-001
```

วางโฟลเดอร์ `ortho/CF-001` ไว้ใน repository แล้วใส่ช่อง URL ออร์โธว่า `ortho/CF-001/{z}/{x}/{y}.png` ชนิด XYZ tiles
(GitHub แนะนำให้ repository ไม่เกิน 1 GB ถ้ามีหลายแปลง ให้ย้ายไป Cloudflare R2 หรือ Google Cloud Storage แล้วใส่ URL เต็มแทน)

## 7. ข้อควรรู้

- **ป้ายชื่อบนแผนที่ฐานเป็นภาษาอังกฤษ** เพราะตัวแสดงผลแผนที่ยังวางสระและวรรณยุกต์ภาษาไทยไม่ถูกตำแหน่ง ส่วนชื่อแปลงและข้อมูลทั้งหมดแสดงเป็นภาษาไทยปกติ
- ในพื้นที่บนดอย OpenStreetMap มีข้อมูลอาคารและขอบเขตป่าไม่ครบ ภาพดาวเทียมหรือออร์โธของแปลงจะให้ภาพที่ชัดกว่า
- ภาพพาโนรามาจะถูกเก็บ 2 ขนาด คือขนาดเต็ม (กว้างไม่เกิน 8192 px) และขนาด 4096 px สำหรับมือถือที่แสดงภาพใหญ่ไม่ได้
- วีดีโอให้อัปขึ้น YouTube แบบ **ไม่เป็นสาธารณะ (Unlisted)** แล้ววางลิงก์ เว็บจะฝังเครื่องเล่นให้
- เว็บนี้เปิดให้สาธารณะดู ชื่อเจ้าของแปลงและพิกัดจะเห็นได้ทุกคน ควรขอความยินยอมจากเกษตรกรก่อนเผยแพร่ (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล) หรือใส่ชื่อกลุ่ม / รหัสแปลงแทนชื่อจริง

```
js/mapstyle.js      สไตล์แผนที่ฐาน
js/data.js          เชื่อมฐานข้อมูล / โหมดสาธิต
js/app.js           การทำงานทั้งหมด
js/demo-data.js     ข้อมูลตัวอย่าง (พิกัดสมมติ)
sql/schema.sql      โครงสร้างฐานข้อมูล
vendor/             ไลบรารี (MapLibre GL, Pannellum, supabase-js, exifr, togeojson, shpjs)
```
